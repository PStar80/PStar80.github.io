# Portfolio Background Artwork

Generated with the built-in image generation tool for Paul Sattaur's portfolio. These are decorative scenes, not technical diagrams or application screenshots.

## Cybernetic Scene

- Web asset: [`public/assets/cybernetic-scene.webp`](../public/assets/cybernetic-scene.webp)
- Style reference: the [public PStar80 GitHub avatar](https://avatars.githubusercontent.com/u/225520620?v=4), retrieved 18 November 2026 UTC.
- Composition: stationary environment for the Expertise section; detailed optical machinery at the edges and a calmer center.

### Generation Prompt

Use case: stylized-concept. Create a NEW wide landscape website background, 16:9 composition at high resolution, for the personal portfolio of a full-stack software engineer. The attached image is a STYLE REFERENCE only: carry forward the dark graphite and silver cybernetic materials, electric-blue and cyan circuitry, and luminous optical processors, but do NOT include the person, face, chair, hands, or any humanoid. Scene: a cinematic, beautifully engineered futuristic cybernetic chamber, viewed at an oblique angle, with precision-machined metallic panels, fine circuit pathways in dimensional walls, a few large circular optical processors and elegant data conduits. It should feel like the world behind the reference portrait. Composition: strong architectural depth and perspective, richer machine details on the left and right edges and upper corners, a quieter dark central area across the middle-lower part for website cards. The scene remains atmospheric but tangible, with recognizable metal forms and carefully controlled luminous traces. Lighting: cool electric blue and cyan rim lighting, selective silver reflections, deep navy shadows; use no purple, pink, red, or rainbow colors. Bright details must remain visible even beneath a mild dark website overlay. Premium cinematic 3D realism, disciplined detail and clean composition. No text, no letters, no typography, no logos, no watermark, no foreground interface, no dashboard, no person, no brain. This is a full-bleed background image only, not a website mockup.

## Neural Scene

- Web asset: [`public/assets/neural-scene.webp`](../public/assets/neural-scene.webp)
- Style reference: the embedded brain/workflow artwork in the [PStar80 profile hero](https://github.com/PStar80/PStar80/blob/main/assets/profile/hero.svg).
- Composition: neural core on the right, with quieter space to the left for GitHub Activity panels.

### Generation Prompt

Use case: stylized-concept. Create a NEW wide landscape 16:9 cinematic background image for a software engineer's portfolio GitHub Activity section. The attached existing brain-and-workflow banner is a visual reference, not an edit target. Reimagine its glowing neural core and connected workflow pathways as a more sophisticated, immersive environment. Scene: a luminous electric-blue neural brain suspended above an elegant dark graphite and machined-silver platform, with finely engineered fiber-optic data conduits and circuit pathways branching through a deep futuristic chamber. Place the recognizable neural brain prominently toward the upper-right third / right edge, so the left and center have quieter darker space for foreground website panels. Let beautiful blue conduits extend along the edges and lower foreground. Do NOT include floating app windows, code signs, graphs, icons, text, or literal diagram boxes: this is atmospheric artwork, not a UI or technical diagram. Material language: dark graphite, brushed and polished silver, precise beveled forms, luminous electric-blue/cyan light traces. Lighting: cinematic cool rim lighting and selective reflections, tangible depth, medium-dark navy atmosphere with visible details. Keep highlights controlled rather than a dense wall of neon. Coordinated with a cybernetic circuitry chamber in the same dark blue metallic style. No people or faces, no text, no letters, no logos, no watermark, no purple/pink/rainbow. Full-bleed image only, not a website mockup.

## Usage

Use these as stationary section backgrounds with foreground content scrolling above them. Avoid a heavy uniform dark overlay that erases the metallic details. Protect text contrast through the dark foreground cards and localized gradients. Retain the current avatar portrait as its own asset; these scenes do not replace or alter it.


## Web Delivery

Original generation PNGs are archived separately and are intentionally excluded from this public repository. The page serves same-size WebP encodings at quality 88: `public/assets/cybernetic-scene.webp` (350,530 bytes) and `public/assets/neural-scene.webp` (211,918 bytes). Encoding preserves the composition and dimensions; no editorial image changes were applied.
